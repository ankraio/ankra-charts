FIRST LOGIN - CHANGE THE SEEDED PASSWORD:
  A fresh installation seeds the user "admin" with the password "adminpass".
  Log in and change it before anyone else can reach the Service{{ if .Values.ingress.enabled }} - this
  release exposes the app through an Ingress, so treat the default credential
  as already public{{ end }}.

Network:
{{- if .Values.networkPolicy.enabled }}
  A NetworkPolicy limits this pod to DNS and its own namespace, in both
  directions{{ if or .Values.networkPolicy.ingress.allowedNamespaces .Values.networkPolicy.ingress.extra .Values.networkPolicy.egress.extra }}, plus the extra rules from your values{{ end }}. An SMTP relay or an
  out-of-namespace database needs a networkPolicy.egress.extra rule. This is
  only enforced if your CNI implements NetworkPolicy - check with:

    kubectl -n {{ .Release.Namespace }} describe networkpolicy {{ include "isms-builder.fullname" . }}
